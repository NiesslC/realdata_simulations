# Statistical parametric simulation studies based on real data

<!-- badges: start -->
<!-- badges: end -->

This repository contains the code and results of the manuscript
“Statistical parametric simulation studies based on real data” by
Christina Sauer, F. Julian D. Lange, Maria Thurow, Ina Dormuth, and
Anne-Laure Boulesteix (<https://arxiv.org/abs/2504.04864>).

## Example 1: Two-arm randomized controlled trial with an ordinal outcome (`ordinal/`)

### File description

#### `ordinal/code/`

- `01_script_generate_probabilities.R`:  
  Defines researcher-specified ordinal outcome probabilities, loads the
  data extracted from articles published in *The New England Journal of
  Medicine* (`data/tablesample_final.xlsx`), transforming the extracted
  empirical distributions into probabilities, calculates some measures
  to characterize the probabilities (e.g., relative effect), and saves
  the researcher-defined probabilities and real-data-based probabilities
  along with the calculated measures as `data/probabilities.RData`.

- `02_script_simuldat_statesdat_estimdat_performdat.R`:  
  Runs the simulation described in Section 4.1 of the manuscript,
  generating and saving the simulated datasets (saved in
  `data/simulation/` together with the random number generator states)
  and the estimates datasets (saved in `results/rdata/`), before
  processing and aggregating the estimates data to generate the
  performance measures dataset, which is saved as
  `results/rdata/performdat.RData`.

- `03_results_method_performance.R`:  
  Produces figures and tables shown for this example in the manuscript
  (main text and supplement) and saves figures in `results/plots/`.

- `_fcts.R`:  
  Functions for executing the simulation (see in-file function
  descriptions for details).

#### `ordinal/data/`

- `simulation/`:  
  Empty in the repository, but after running
  `code/02_script_simuldat_statesdat_estimdat_performdat.R`, this folder
  would contain 95 `.RData` files (total size: approx. 173 MB) with the
  simulated datasets for the 95 investigated DGMs.

- `probabilities.RData`:  
  Contains the researcher-defined and the real-data-based ordinal
  outcome probabilities along with measures characterizing the
  probabilities (e.g., relative effect).
  <!-- Could be regenerated by running `code/01_script_generate_probabilities.R`. -->

- `tablesample_final.xlsx`:  
  Spreadsheet containing a) general meta data about the 270 screened
  articles published in *The New England Journal of Medicine*, b)
  columns documenting the eligibility assessment of the trials/outcomes
  (see Supplementary Section A.2.1), and c) empirical distributions and
  further information extracted for the 15 included outcomes.

#### `ordinal/results/`

- `plots/`:  
  Contains the three figures created and saved by running
  `code/03_results_method_performance.R`.

- `rdata/`:  
  Contains the performance measures dataset (`performdat.RData`). After
  running `code/02_script_simuldat_statesdat_estimdat_performdat.R`,
  this folder would also contain the estimates datasets
  `estimdat_allnejm_effect.RData` (size: approx. 1.47 GB) and
  `estimdat_alluser_effect.RData` (size: approx. 66 MB), which contain
  the *p*-values from the four methods for every repetition of every
  DGM.

### How to reproduce the results

To reproduce the figures and tables presented in the paper, run
`03_results_method_performance.R`. All data/results files needed to
execute this script are included in the repository.

To reproduce the simulation (thereby reproducing `performdat.RData`,
i.e. the performance measures dataset used in
`03_results_method_performance.R`), run
`02_script_simuldat_statesdat_estimdat_performdat.R`. With the setup
specified below, executing this script took approx. 15 minutes, saving
1.71 GB of data in the process (as detailed above).

### Hardware specification and session information

The parallelized code for the simulation (see
`02_script_simuldat_statesdat_estimdat_performdat.R`) was executed using
10 Intel Xeon Platinum 8280 CPU @ 2.70GHz cores on a Linux server with
224 such cores and approx. 1.51 TB of RAM.

## Example 2: Differential gene expression analysis (`deanalysis/`)

### File description

#### `deanalysis/code/`

- `01_script_get_tcga_datasets.R`:  
  Downloads all 33 TCGA datasets (RSEM TPM gene expression values) using
  the `curatedTCGAData` package and saves them as
  `data/tcga_datasets.RData`.

- `02_script_get_tcga_parameters.R`  
  <!-- TODO Generates and saves a) a list containing the estimated mean and dispersion parameters and the filtered count from the original count dataset for the TCGA datasets with paired samples (saved as `data/tcga_parameters.RData`) and b) a . -->

- `03_script_simuldat_estimdat.R`:  
  Runs the simulation described in Section 4.2 of the manuscript,
  generating and saving first the simulated datasets (saved in
  `data/simulation_degenes/`) and then the estimates datasets (saved in
  `results/rdata/rdata_degenes/`).

- `04_script_performdat.R`:  
  Processes simulation results (i.e. the estimates datasets generated by
  running `03_script_simuldat_estimdat.R`) into a unified dataset and
  saves it as `results/rdata/performdat_degenes.RData`.

- `05_results_method_performance.R`:  
  Produces figures and tables shown for this example in the manuscript
  (main text and supplement) and saves figures in `results/plots/`.

- `_fcts.R`:  
  Functions for executing the simulation, some of which are based on or
  modified versions of functions from the `compareDEtools` package (see
  in-file descriptions for details).

#### `deanalysis/data/`

- `simulation_degenes/`:  
  Empty in the repository, but after running
  `code/03_script_simuldat_estimdat.R`, this folder would contain 5,600
  `.rds` files (total size: approx. 1.88 GB) with the simulated datasets
  for the 112 investigated DGMs.

- `tcga_parameters_metadata.RData`  
  <!-- TODO containing estimated mean and dispersion parameters and filtered count from original count dataset. Generated by running `code/02_script_get_tcga_parameters.R`. -->

- After running `code/01_script_get_tcga_datasets.R`, this folder would
  also contain `tcga_datasets.RData` (size: approx. 1.59 GB).

- After running `code/02_script_get_tcga_parameters.R`, this folder
  would also contain `tcga_parameters.RData` (size: approx. 250 MB).

#### `deanalysis/results/`

- `plots/`:  
  Contains the six figures created and saved by running
  `code/05_results_method_performance.R`.

- `rdata/`:  
  Contains performance measures dataset (`performdat_degenes.RData`),
  which is generated by running `code/04_script_performdat.R` using the
  estimates datasets saved in the following subfolder:

  - `rdata_degenes/`:  
    Empty in the repository, but after running
    `code/03_script_simuldat_estimdat.R`, this folder would contain
    61,600 `.rds` files (total size: approx. 40 GB) with the estimates
    for the 11 methods on the 5,600 simulated datasets.

### How to reproduce the results

To reproduce the figures and tables presented in the paper, run
`05_results_method_performance.R`. All data/results files needed to
execute this script are included in the repository.

To reproduce the simulation (thereby reproducing
`performdat_degenes.RData`, i.e. the performance measures dataset used
in `05_results_method_performance.R`), run
`01_script_get_tcga_datasets.R`, `02_script_get_tcga_parameters.R`,
`03_script_simuldat_estimdat.R`, and `04_script_performdat.R`. The
simulation is conducted using the `compareDEtools` package, which is
available here: <https://github.com/unistbig/compareDEtools>.

In addition to the already mentioned large amount of data being
generated and saved, the simulation takes a long time to execute,
especially, the generation of the 61,600 estimates datasets in
`03_script_simuldat_estimdat.R` (i.e. the part where the 11 investigated
methods are applied to 5,600 simulated datasets). With the setup
specified [below](#hardware-specification-and-session-information-1)
(one core per TCGA dataset), the parallelized code chunks in that script
had the following runtimes:

- Methods not changing the state of the random number generator (RNG;
  edgeR, DESeq.pc, DESeq2, voom.tmm, voom.qn, and voom.sw): approx.
  1,200 minutes
- Methods changing the state of the RNG:
  - edgeR.ql (edgeR.GLMQL): approx. 15 minutes
  - edgeR.rb (edgeR.GLM.Robust): approx. 90 minutes
  - ROTS: approx. 1,600 minutes
  - BaySeq: approx. 5,500 minutes
  - PoissonSeq: approx. 17 minutes

Note that these are the runtimes to finish the execution for all workers
/ TCGA datasets. For the methods not changing the state of the RNG and
BaySeq, the runtime was considerably shorter for some of the TCGA
datasets (on a per-TCGA-dataset basis, the median runtime was approx.
850 minutes for the methods not changing the state of the RNG and
approx. 5,200 minutes for BaySeq).

### Hardware specification and session information

The parallelized code for the simulation (see
`03_script_simuldat_estimdat.R`) was executed using 14 Intel Xeon
Platinum 8280 CPU @ 2.70GHz cores on a Linux server with 224 such cores
and approx. 1.51 TB of RAM.
